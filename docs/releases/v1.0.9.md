# ArHub 1.0.9

这是 ArHub 首个完整 Windows 开源发行版。它把 Agent 对话、文件树、编辑器、
产物预览、检查点和多步骤科研工作流放在同一个桌面工作台中，并允许每个 Agent
独立连接 DeepSeek、GLM 或其他 OpenAI Chat Completions 兼容服务。

![ArHub 文件、编辑器与 Agent 工作台](https://raw.githubusercontent.com/jiashuoyan0-maker/ArHub/v1.0.9/assets/screenshots/04-files-editor-agent.png)

## 主要内容

- Codex 式任务工作台：对话保持在主区域，文件和编辑器按需从侧边展开。
- 执行者、审稿者和编辑器助手可分别配置 Base URL、API Key 和模型 ID。
- 支持 Agent 工具循环、文件 diff/apply/undo、工作流检查点、暂停恢复和产物管理。
- 支持 Markdown/LaTeX 编辑、PDF/DOCX/图片预览以及 DOCX 导出。
- 亮色与暗色主题、磨砂层次和 ArHub 全新图标。
- 声明式 Skill、工作流模板和 Agent profile 扩展入口。

![ArHub 多 Agent 模型设置](https://raw.githubusercontent.com/jiashuoyan0-maker/ArHub/v1.0.9/assets/screenshots/05-model-settings-light.png)

## 完整离线运行时

安装包内置并锁定以下 Windows x64 组件，用户无需单独安装：

- Python 3.11.9 及完整依赖环境
- Node.js 24.13.0、npm、Corepack 与 Claude Code 兼容运行时
- Git for Windows 2.52.0
- Pandoc 3.7.0.2
- Draw.io Desktop 28.2.5
- MiKTeX 25.12 / XeLaTeX

本次安装包使用 runtime 锁 `2026.07.30.3`。发布前已迁移停止维护的
`PyPDF2`、升级受安全公告影响的 Python 包，并对完整捆绑环境执行
`pip-audit`；发布候选中没有检测到已知 Python 依赖漏洞。

运行时版本、目录统计、Python 包全集和关键文件哈希均记录在仓库的
`packaging/` 目录。正式构建不会覆盖 Python、Node.js、Git、Draw.io 等组件的
上游厂商签名。

## 安装与验证

1. 下载 `ArHub-Setup-1.0.9-x64.exe`。
2. 双击安装；这是当前用户的一键安装，不要求预先安装 Python 或 Node.js。
3. 在“系统设置”中填写自己的模型地址、API Key 和模型 ID。

安装包约为 1.56 GiB，解压后的离线运行时约为 6.52 GiB。建议预留至少 10 GiB
可用空间；安装器需要展开约 8.7 万个文件，慢速磁盘或实时杀毒扫描会延长首次
安装时间。

正式附件必须同时满足以下门槛后才会由工作流发布：

- 安装器、ArHub 主程序、更新提权助手和卸载器具有可信且带时间戳的
  Authenticode 签名。
- 安装后后端健康检查成功、前端加载成功，并能完成静默卸载。
- `SHA256SUMS.txt`、CycloneDX SBOM、更新 blockmap 和 GitHub 构建来源证明均已生成。

可以在 PowerShell 中校验下载文件：

```powershell
Get-FileHash .\ArHub-Setup-1.0.9-x64.exe -Algorithm SHA256
```

将输出与同一 Release 中的 `SHA256SUMS.txt` 对照。

## 自动更新与维护

应用使用 `electron-updater` 从本仓库的签名 Release 获取更新，并同时校验
SHA-512 与发布者证书。Dependabot、CodeQL 和每周维护工作流持续检查 npm、
后端及完整捆绑 Python 环境、GitHub Actions、安全公告及完整运行时版本。

## 已知边界

- 当前生产前端来自仓库中审计后的 `dist/` 产物；原始 Vite 模块图尚未完全恢复。
- OpenAI-compatible 并不意味着不同模型的工具调用、视觉输入和上下文能力完全相同。
- 安装包包含完整科研运行时，首次安装可能持续十分钟以上；安装期间不要强制结束进程。
- API Key 仅应保存在本机设置中，不要提交到 Issue、日志、截图或仓库。

完整使用方式、更多截图和开发说明见仓库
[README](https://github.com/jiashuoyan0-maker/ArHub#readme)。
