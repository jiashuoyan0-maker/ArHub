# ArHub v1.0.10

ArHub v1.0.10 focuses on making the desktop Agent easier to install, configure,
and extend. This release introduces a much smaller Lite installer while keeping
the open-model workflow, local Claude Code integration, and the redesigned
frosted-glass workspace.

## 中文

### 主要更新

- 新增约 326 MiB 的 Lite 安装包，相比上一版 Full 安装包缩小约 80%。
- 安装器支持自定义安装目录，包括带空格的路径。
- 支持 DeepSeek、GLM、OpenAI 和通用 OpenAI-compatible Provider。
- 支持 Provider 自动识别、模型独立配置和思考强度选择。
- 可以选择使用本机已经安装并登录的 Claude Code。
- Agent 对话支持流式输出、终止、附件上传、当前模型与运行时显示。
- 新增 Manifest 扩展中心、Agent Profiles、Diagram Studio 和 Web Studio。
- 修复 DOCX 导出 Skill 缺失、路径隔离和多项安装烟测问题。
- 更新磨砂透明界面、设置页、Agent 工作台和 README 截图。

### 安装说明

Windows 安装包目前未使用 Authenticode 证书签名。SmartScreen 可能显示
“Windows 已保护你的电脑”或“未知发布者”。请确认文件来自本仓库 Release，
核对 SHA256 后选择“更多信息”并继续运行。

模型设置、API Key、日志和工作区存放在 `%APPDATA%\ArHub`，不会因为更换安装
目录或卸载应用而自动删除。请勿把真实 API Key 提交到仓库、Issue、截图或日志。

## English

### Highlights

- Adds a Lite installer of about 326 MiB, roughly 80% smaller than the previous Full installer.
- Supports custom installation directories, including paths containing spaces.
- Supports DeepSeek, GLM, OpenAI, and generic OpenAI-compatible providers.
- Adds provider detection, per-agent model configuration, and reasoning-effort controls.
- Can use an existing local Claude Code installation and login.
- Adds streaming Agent output, stop, attachments, and runtime/model indicators.
- Adds a manifest-based extension center, Agent Profiles, Diagram Studio, and Web Studio.
- Fixes the missing DOCX export Skill, path isolation, and installer smoke-test issues.
- Refreshes the frosted-glass workspace, settings UI, Agent composer, and screenshots.

### Installation

The Windows installer is currently unsigned with Authenticode. SmartScreen may
show an unknown-publisher warning. Download only from this repository's Release,
verify the SHA256 checksum, then use **More info** to continue if Windows blocks it.

Model settings, API keys, logs, and workspaces are stored in `%APPDATA%\ArHub`
and are not removed automatically when the app is moved or uninstalled. Never
publish real API keys in the repository, Issues, screenshots, or logs.
