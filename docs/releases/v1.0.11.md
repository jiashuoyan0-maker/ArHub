# ArHub v1.0.11

ArHub v1.0.11 重新提供 Full 安装包，并补齐每个 Agent 的思考强度配置。

## 中文

### 主要更新

- 同时发布 **Lite**（约 326 MiB）与 **Full**（约 1.56 GiB）两种安装包。
  Full 内置完整离线运行时（TeX、Draw.io、Pandoc、Git 与科学计算工具链），
  开箱即用，适合新手和需要完整工具链的用户。
- 思考强度支持进一步补齐：设置页的 Agent 运行时卡片现在可以为
  执行者、审稿者和编辑器助手分别选择思考强度（默认/关闭/低/中/高/极高/最大）。
- Agent 输入栏继续提供思考强度下拉：开放模型映射 GLM 思考模式与 OpenAI
  reasoning effort，本机 Claude Code 映射 `--effort`。
- 两个安装包共用 `%APPDATA%\ArHub` 设置与工作区，可随时切换而不迁移数据。

### 已知边界

Windows 安装包仍未使用 Authenticode 证书签名，SmartScreen 可能提示未知发布者；
请只从本仓库 Release 下载并核对 SHA256。Full 安装包较大，安装时需要约 10 GiB
可用空间。

## English

### Highlights

- Ships both **Lite** (~326 MiB) and **Full** (~1.56 GiB) installers. Full
  bundles the complete offline runtime (TeX, Draw.io, Pandoc, Git, and
  scientific-computing tools) for out-of-the-box use.
- Per-agent reasoning-effort controls: the Agent runtime card in Settings now
  covers the executor, reviewer, and editor assistant (default/off/low/medium/
  high/xhigh/max).
- The Agent composer continues to expose a reasoning-effort selector, mapping
  to GLM thinking mode and OpenAI reasoning effort for open models, and to
  Claude Code's `--effort` for the local runtime.
- Both profiles share `%APPDATA%\ArHub`, so users can switch between Lite and
  Full without migrating data.

### Known boundary

The Windows installers are still unsigned with Authenticode; SmartScreen may
warn about an unknown publisher. Download only from this repository's Release
and verify SHA256. The Full installer needs roughly 10 GiB of free space to
install.
